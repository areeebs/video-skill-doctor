# Contributing

Thanks for helping make setup easier for people using local video skills.

Please keep reports evidence-based: include the skill document and line that mentions a tool, and say whether the tool is required or optional according to that document. Avoid rules that turn a casual mention into a definite requirement. The checker should never execute scanned files or print environment-variable values.

For a proposed change, explain the user problem, the behavior you expect, and how someone can review it manually. This is an early learning project; changes may take time to review.
